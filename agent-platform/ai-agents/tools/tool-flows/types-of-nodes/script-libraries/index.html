    List of Supported Libraries¶

    The following pre-existing libraries can be selected for use in the script editor of the Function Node.

    • json
    • enum
    • Numerical Libraries: numPy, pandas, collections, math, cmath, statistics, and random.
    • String Manipulation Libraries: re and textwrap.
    • Date-time Libraries: datetime, time, and calendar.
    • Itertools

    The libraries mentioned above are imported and made available in the function node in the following formats:

    import json
import numpy
import scipy
import pandas
import collections
import math
import cmath
import statistics
import random
import enum
import re
import textwrap
import datetime
import time
import calendar
import itertools
