# Introducing All-new Agent Platform

We are excited to announce the first version of Agent Platform, our enterprise-grade multi-tool orchestration platform. The all-new Agent Platform is a comprehensive solution for enterprises to develop, deploy, and manage AI-powered business applications. It enables the orchestration of intelligent tools across service, work, and process automation while maintaining enterprise-grade security and governance. 

## Key Components

The Platform's key components provide comprehensive capabilities that empower organizations to efficiently scale and manage AI deployments across the AI lifecycle.

<img src="../images/agent-platform-overview.png" alt="Agent Platform" title="Agent Platform">

### Multi-Agent Orchestration

It enables users to define agent behaviors, skills, and integrations through low-code, declarative programming. This allows both technical and non-technical users to create and manage intelligent agents easily. It gives agents advanced reasoning and planning skills, enabling them to analyze their environment, act effectively, and learn from the outcomes to operate autonomously and adaptably.

It also provides real-time streaming of agent interactions across voice and chat channels, enabling seamless user experiences and dynamic agent-based applications.

### Action / Tools

It provides versatile tools for agent development, using both low-code and code-based approaches. It also features visual workflow builders and support for custom coding in JavaScript and Python.

It also offers extensive pre-built integrations, connecting agents with over 100 popular enterprise applications, enabling data interaction and task performance across enterprise systems.

### Search / RAG 

It provides secure access to data through 100+ pre-built data agents with role-based access controls, enabling seamless retrieval of information from diverse systems and repositories. The component uses AI to extract and enrich relevant data from connected sources. It goes beyond simple retrieval to understand context and semantics, allowing for accurate information extraction and enrichment with additional insights.

The component employs a hybrid approach to retrieval, combining multiple methods to deliver the most relevant and comprehensive results. It supports agentic retrieval, where multiple agents collaborate and coordinate their efforts to find and retrieve information efficiently. Additionally, the component is context-aware, taking into account the specific context and requirements of each retrieval request. By considering factors such as user preferences, current tasks, and previous interactions, it can tailor the retrieved data to the specific needs of the user or application.

### Interaction Context

It provides comprehensive management of the interaction state throughout its entire lifecycle. It tracks and maintains the context of each interaction, ensuring a seamless and coherent user experience. By keeping a record of previous interactions, user preferences, and relevant data, the component enables agents to maintain continuity and provide contextually appropriate responses.

### Models

The component offers a comprehensive set of capabilities for managing and leveraging AI models within the agent platform. It provides the flexibility to fine-tune and optimize models specifically for different domains or use cases. This allows organizations to adapt models to their unique requirements, improving performance and accuracy in specific contexts. 

It also allows for easy deployment of state-of-the-art open-source models, enabling organizations to leverage the latest AI advancements and pre-trained models without extensive development. Additionally, the component allows integration with third-party model providers, extending the range of available model options and enabling organizations to choose the best models for their needs.

### Prompts

The component, with its Prompt Studio and Prompts Library, allows for efficient prompt design, management, and reuse across projects and teams. It fosters team collaboration through features like real-time co-editing and commenting, enabling multiple users to develop and test prompts together.

It also tracks prompt changes, allowing users to revert to previous versions. It integrates with the overall agent platform, allowing prompts to be seamlessly deployed to live agents after validation checks and approvals.

### Evaluation

The component thoroughly assesses agent performance by combining AI-driven automated evaluations with human evaluator insights, ensuring objective measurement and a well-rounded analysis. It allows human experts to assess and provide qualitative feedback on agent performance, complementing automated evaluations for a comprehensive performance review.

It also empowers organizations to define their own custom scoring rubrics, allowing them to tailor the evaluation criteria to their specific requirements and goals. 
Continuous monitoring tracks agent performance metrics in real-time, using data from conversation logs, user feedback, and system metrics. This allows organizations to identify trends, spot areas for improvement, and optimize agent performance.

### AI Safety 

The component safeguards data privacy and content appropriateness by anonymizing personally identifiable information (PII) and sensitive data. This helps organizations comply with data protection regulations and maintain user trust. It also uses input and output guardrails, including advanced content filtering, to maintain appropriate content standards and ensure respectful communication.

The component also provides granular role-based access controls to data, ensuring that users can only access data relevant to their job functions.

### Analytics

The component provides insights into the usage and performance of agent-based systems by capturing detailed activity data from the underlying models and agent applications. It also records detailed session logs and conversation histories in addition to usage logs. This allows organizations to track and analyze individual user interactions with agents, providing a granular view of how conversations unfold over time.

The component provides a range of metrics and dashboards to make the insights actionable. These visualizations present key performance indicators (KPIs) and metrics in an intuitive and easily digestible format.

### Observability

It provides deep visibility into agent-based systems, enabling organizations to understand AI decision-making. End-to-end tracing of the orchestration allows developers to follow the flow of data and logic, facilitating debugging and optimization.

It prioritizes the explainability of agent reasoning and actions. It goes beyond simply tracing the flow of data and provides insights into the underlying rationale behind agent behaviors. This explainability feature helps users understand why specific actions were taken or recommendations were made by the agents. It exposes the key factors, rules, and constraints that influenced the agent's decision-making process. 

To further enhance transparency and understanding, the component supports the streaming of agent thoughts. This unique feature allows users to access a step-by-step view of the agent's "thought process" as it analyzes information, considers options, and reaches conclusions. This level of transparency empowers users to gain a deeper understanding of how the agent arrives at its decisions, promoting trust and facilitating collaboration between humans and AI agents.

### Agent Protocol

The component establishes a solid foundation for agent communication and collaboration using an end-to-end API, with support for multimodal content, real-time streaming, and external agent integration. 

It enables agents to understand and generate diverse types of data, process information in real-time, and seamlessly integrate with external systems. This comprehensive protocol empowers organizations to build sophisticated agent-based solutions that can interact with users and other agents in a natural and efficient manner, ultimately enhancing the overall user experience and driving better outcomes.

### SDKs

The component provides a comprehensive set of development kits that empower developers to build and integrate various aspects of the agent platform efficiently. These SDKs cover essential platform components such as Agents, Tools, RAG (Retrieval Augmented Generation), and Traces, offering standardized interfaces and managed infrastructure to streamline the development process.

### Enterprise Grade CI/CD

The component offers granular versioning and multi-stage deployment capabilities to support a rigorous software development lifecycle for agent-based solutions. It allows organizations to establish separate environments (e.g., QA, UAT, Prod) for thorough testing and validation, ensures consistent deployments, and streamlines the development process to deliver high-quality, reliable solutions.

### Collaboration and Audit

The component allows teams to develop, test, and deploy agent-based solutions collaboratively. Customizable roles and permissions ensure clear responsibilities and access levels. Comprehensive audit logs track all activities, ensuring traceability, accountability, and compliance. This creates a transparent and accountable environment for effective collaboration and fosters a culture of shared responsibility.

### Marketplace

It provides a vast library of prebuilt templates for agents and tools across various domains and use cases. This accelerates development by offering customizable, ready-made components, eliminating the need to build from scratch.
