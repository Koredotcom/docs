# About Knowledge Tools

Agent Platform enables easy integration with **AI for service** and offers seamless search capabilities on content from various sources. At the core of this integration is the Search AI application, which facilitates Retrieval-Augmented Generation (RAG)-based search across a variety of content sources, such as enterprise knowledge bases, document repositories, FAQs, and third-party systems.
This advanced RAG-based architecture enables autonomous agents to deliver context-aware, accurate, and timely responses by using information pulled from knowledge sources.

## Key Benefits 

* Enable developers to leverage knowledge capabilities in their agents without coding.
* Improve agent performance by providing access to relevant, up-to-date information.
* Enhanced data coverage by ingesting content from various sources including websites, help centers, CRM systems, and internal documentation.

Example

If an AI agent is configured to provide information about a company’s product offerings and the relevant content is available on the company’s public website. By using Search AI, the agent can set up a knowledge tool that indexes the website’s content. When users ask questions such as “What are the AI Solutions offered by the company?”, the agent uses the knowledge tool to retrieve and present accurate information directly from the indexed content, ensuring responses are both relevant and up to date.

Points to Note:

Knowledge Tools are common across an agentic app.
