# Kore.ai Agent Platform v0.1.0 (Preview)

We're excited to introduce the preview version of Kore.ai's Agent Platform! This early access release allows you to explore our unified enterprise solution for building multi-agent AI applications before the official launch.

## Key Features

* **Agentic Apps**: Built-in agentic AI capabilities with complete no-code development tools for multi-agent AI solutions. Multi-Agent Orchestration to coordinate task execution across AI agents, routing requests based on capabilities.

* **Actions or Tools**: Integration framework with connectors and APIs enabling AI agents to interact with enterprise systems.

* **Knowledge**: Retrieval system with connectors for AI agents to access and enrich organizational knowledge.

* **Model Hub**: System to fine-tune and host AI models with enterprise data, supporting various model types.

* **Prompt Studio**: Environment to create and test prompts, with versioning for optimal LLM performance.

* **Evaluation Studio**: System to measure LLM performance using customizable metrics and combined AI-human evaluations.

* **AI Safety and Observability**: Framework providing governance, controls, and logging for safe, transparent AI operations.

## Important Notes

* Performance variations and minor inconsistencies may occur during this preview phase.

* Features may be modified based on user feedback.

* While we aim for backward compatibility, some features may require updates for optimal design.

* We recommend using the Evaluation Studio to assess Agentic Apps before production deployment
