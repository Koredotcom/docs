# Dialog Management - NEW


## Overview

Dialog page provide a central workspace to create, manage, and search dialogs within an AI Agent. Hover over the dialog to view the edit, clone, delete, and more options. From more options you configure dialog settings, manage interruptions, and amend behavior.


 The experience also supports searching for specific dialog tasks, managing shared dialog components such as entities and webhooks, creating new dialog tasks, and testing the AI Agent by simulating user interactions.

## Manage Components

The Dialog Components section, where you can manage entities, webhooks, messages, agent transfers, etc., that are in use within all Dialog Tasks within your AI Agent.
