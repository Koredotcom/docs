# Multilingual Support in SearchAI 

Search AI currently supports **English** and **Ukrainian** to improve the user experience. With this feature, users can:

* **Add and manage content** in multiple languages.
* **Understand and respond to queries** in supported languages.
* **Provide search results and answers** in the same language as the query.

Support for more languages will be continuously added to make Search AI more accessible and user-friendly.
