# Agent AI Migration from XO v10 to XO v11

XO v11 offers a unified, AI-powered platform with enhanced capabilities, improved usability, and a superior user experience. Migrating from Agent AI XO v10 to v11 ensures continued access to innovation, as all future updates will be available exclusively on XO v11. For more information on benefits and upgrade journey, refer to <a href="https://docs.kore.ai/agentassist/getting-started/migration-from-agent-ai-xo-v10-to-agent-ai-xo-v11/">Migration from XO v10 to XO v11</a>.

!!! note

    Existing XO v10 customers will be notified of the Agent AI end-of-life cycle. Transitioning to XO v11 ensures uninterrupted service and access to the latest advancements.
