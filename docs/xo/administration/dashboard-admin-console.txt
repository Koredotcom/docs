# Dashboard (New Admin Console)

!!! Note

    This page refers to the Dashboard page of the Admin Console, for information on the Analytics Dashboard of the XO Platform [refer here](../analytics/overview/users-dashboard.md).

When you access the [Admin Console](adminconsole.md){:target="_blank"}, you are directed to its Dashboard page.

The **Dashboard** page displays assistant activity details and provides a user overview for your company account.

## Dashboard Metrics

### Real-time Status

This gives an overview of your entire enterprise account at a given point in time. It's set to refresh every 1  minute, which can be customized using the dropdown next to the Refresh button.

The Real Time Status includes:

* **Active Bots** – assistants that have one or more active sessions. Clicking on "View Details" displays the name of the Active Bot along with the number of users interacting with it.
* **Active Channels** – clicking on "View Details" displays the list of active channels along with the number of users using the same.
* **Active Agent Sessions** – agent sessions that are in progress at a given instance.
