# Active Console Configuration

Active Console Configuration ensures seamless management of agent sessions when the  Console is opened in multiple tabs, devices, or browsers. It prompts agents to transfer an existing session to a new tab or device, preventing concurrent use until the transfer is confirmed. The feature maintains session continuity, establishes new connections as needed, and logs all transfer actions in audit reports.

## Configuration

Steps to enable active console configuration:

1. Go to Contact Center AI > Settings > System Settings > Active Console Configuration.  
    <img src="../images/active-console-config.png" alt="Active Console Configuration" title="Active Console Configuration" style="border: 1px solid gray; zoom:70%;">

2. The functionality is enabled by default. Turn off the toggle to disable it.  
    <img src="../images/console-config-disabled.png" alt="Console Config Disabled" title="Config Console Disabled" style="border: 1px solid gray; zoom:70%;">
