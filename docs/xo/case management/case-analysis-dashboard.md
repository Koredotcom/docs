# Analyze Cases

## Dashboard

The case management dashboard within the Analyze section provides detailed insights into cases and tasks metrics. This enables users, such as app owners, supervisors, and agents to filter, monitor, and track metrics based on their specific roles.

### Access Dashboard

Access the case management **Dashboard** by navigating to **Contact Center AI** > **Case Management** > **Analyze**> **Dashboard**.

<img src="../case management/images/dashboard.png" alt="Dashboard" title="Dashboard" style="border: 1px solid gray; zoom:70%;">

This dashboard has the following sections:

* Calendar

* Channels

* Cases

* Tasks

### Calendar

#### Date and Time Range Selection

Allows you to select the date range from the calendar for specific conversation interactions and case metrics. The default date range is always the current date selected. 

By selecting the following date ranges, you can filter all agents interaction data:

* **Today**: Displays all interaction data for the current day based on the agent’s time zone.

* **Yesterday**: Displays all interaction data for the previous day based on the agent’s time zone.

* **Last 7 Days**: Displays all interaction data for the last 7 days (excluding today) based on the agent’s time zone.

* **Last 28 Days**: Displays all interaction data for the last 28 days (excluding today) based on the agent’s time zone.

* **Last 30 days**: Displays all interaction data for the last 30 days (not including today) based on the agent’s time zone.

* **Custom Range**: Displays all interaction data for the given date range selected (12:00:00 AM to 11:59:59 PM) based on the agent’s time zone (limited to 31 days).

    <img src="../case management/images/dashboard-calendar.png" alt="Calendar" title="Calendar" style="border: 1px solid gray; zoom:70%;">

### **Channel**

Allows you to filter various agent interaction channels (**All**, **Call**, **SMS**, and **Voice**) by selecting the preferred date and time ranges.

<img src="../case management/images/channels.png" alt="Channel" title="Channel" style="border: 1px solid gray; zoom:70%;">

To filter agent interaction data by channel, choose a conversation channel type, such as **Voice**, **SMS**, or **Email** or **All** channels from the top-right corner of the dashboard. 

# Analyze Cases and Tasks

Provides the options for supervisors to filter cases and tasks for review, assess, and monitor individual cases and tasks assigned. 

## Cases

This feature allows agents to manage and track individual cases throughout their lifecycle.

### Access Cases

Access dashboard cases by navigating to **Contact Center AI** > **Case Management** > **Analyze** > **Cases**.

<img src="../case management/images/channels.png" alt="Cases" title="Cases" style="border: 1px solid gray; zoom:70%;">

The following are the key metrics tracked for cases:

### Total

Displays the frequency of cases that are reopened by agents, indicating potential issues with initial resolutions and real-time count valuee.

<img src="../case management/images/total.png" alt="Total" title="Total" style="border: 1px solid gray; zoom:70%;">

### Reopened

Displays the frequency of cases that are reopened by agents, indicating potential issues with initial resolutions.

<img src="../case management/images/reopened.png" alt="Reopened" title="Reopened" style="border: 1px solid gray; zoom:70%;">

Displays the number of default cases that are not assigned to an agent.

This feature helps agents to organize, prioritize, and manage their workload by handling individual case realted tasks. Supervisors can assign tasks to agents, to track progress, and to enhance performance improvement of the agents.

Shows the number of tasks closed.

Shows the average time that it takes to resolve tasks, from when they are created and closed.

### Tasks Created by Day

Shows the volume of new tasks being generated based on the date range selected.

### Status

View the number of tasks performed, such as **Open**, **In progress**, **On hold**, and **Resolved**.

<img src="../case management/images/status.png" alt="Status" title="Status" style="border: 1px solid gray; zoom:70%;">

You can view the number of tasks at different stages, such as:

* **Open**: Tasks that are not yet started.

* **In Progress**: Tasks that are being actively worked on.

* **On Hold**: Tasks that are paused, due to waiting for further information.

* **Resolved**: Tasks that are completed and resolved.

### Priority

Monitors how agents handle the tasks based on the priority level, such as **Critical**, **High**, **Medium**, **Low**, and **No Priority**.

You can monitor how agents handle tasks based on priority levels:

* **Critical**: Tasks that need immediate attention and resolution.

* **High**: Tasks that are important but do not require immediate attention.

* **Medium**: Tasks with moderate priority.

* **Low**: Tasks that you can address at a later time.

* **No Priority**: Tasks that have no defined priority level.
