# Quality AI Onboarding Guide

## Overview

Quality AI is a post-interaction analytics platform designed to improve agent performance and customer experience in contact centers. It uses AI to automatically evaluate conversations, monitor performance, and support agent coaching.

Quality AI now operates as both a flexible standalone product and an integrated solution with CCAI or Agent AI. 

This guide outlines the complete onboarding process, from initial account access to application configuration and deployment.

### Key Capabilities

* **AI-Powered Quality Assurance**: Automatically scores and evaluates conversations.

* **Real-time Analytics**: Monitors agent performance in real time.

* **Agent Coaching**: Provides insights to enhance agent skills.

* **Multilingual Support**: Analyzes conversations across languages.

* **Flexible Integration**: Works independently or with CCAI and Agent AI.

### Business Value

* Enhances operational efficiency and reduces manual QA workload.
* Improves Customer Satisfaction Score (CSAT) through better coaching.
* Identifies training gaps for cost optimization.
* Automates monitoring for compliance with regulations.

## Deployment Preparation

### Prerequisites

Make sure you have:

* A supported web browser (latest versions of Chrome, Microsoft Edge, Safari, or Firefox). 
* Admin access to the XO Platform account with the appropriate licensing.
* A stable internet connection.
* Your chosen deployment type (mentioned below).


#### **Deployment-Specific Requirements**


#### **Quality AI (Standalone)**


#### Organizations that want complete quality assurance without other Kore.ai systems.



* **Licensing:** Quality AI standalone license
* **Storage:** Minimum 50 GB available for conversation data storage
* **Users:** At least 5 agent seats for meaningful analytics
* **Data Sources:** Access to conversation export capabilities from existing systems
* **Technical Contact:** Designated IT administrator with API integration experience


#### **Quality AI Express**


#### Quick setup with basic analytics.



* **Licensing:** Quality AI Express license
* **AWS Account:** Active AWS account with S3 bucket access (if using AWS S3)
* **File Management:** Ability to generate conversation files in JSON, CSV, or XML format
* **Batch Processing:** The system is capable of processing files in 500-record batches
* **Storage Requirements:**
    * Local staging: 10 GB minimum
    * Cloud storage: S3 bucket with appropriate IAM permissions
* **Network:** Bandwidth to support daily file uploads up to 10 GB


#### **Integrated Deployment (with CCAI or Agent AI)**

Organizations that are already using Kore.ai's contact center tools.



* **Existing Platform:** Active CCAI or Agent AI deployment
* **API Access:** Valid API keys and integration endpoints
* **Real-time Processing:** Network infrastructure supporting real-time data ingestion
* **Metadata Management:** Configured queue IDs and agent email mappings
* **Unified Licensing:** Combined license for Quality AI + CCAI or Agent AI
* **Advanced Requirements:**
    * Queue configuration with unique IDs across all systems
    * Agent metadata synchronization capabilities
    * Real-time conversation streaming infrastructure

**Note:** Internet Explorer mode in Microsoft Edge is not supported.

## **Onboarding Process**


### **Access the XO Platform**

AI for Service (XO Platform) is the foundation platform that hosts Quality AI and other conversational AI tools. 

To sign up for the XO platform**,**



1. Go to the XO Platform [Homepage](https://platform.kore.ai/builder/). The XO Platform hosts all Kore.ai tools, including Quality AI.
2. Sign in using one of the following options:
    * **Email**: Create a personal or admin account.
    * **Single Sign-On (SSO):** Use Google or Microsoft Office 365 credentials. [Learn more](https://docs.kore.ai/xo/getting-started/accessing-the-platform/#new-account-sign-up). 
    * If you do not have an account, sign up using one of the above options.


### **Set Up Your Workspace and Roles**



1. After signing in to the platform, you are directed to the **AI for Service **landing page, where you can:
    * View your subscribed modules
    * Access all Kore.ai applications in one place. [Learn more](https://docs.kore.ai/xo/getting-started/accessing-the-platform/?h=supported#ai-for-service-landing-page).
2. If you are an admin, you can invite other users to the platform after registration ([Learn more](https://docs.kore.ai/xo/getting-started/accessing-the-platform/?h=supported#invite-users-to-your-app-from-the-apps-admin-portal)) and grant them access. [Learn more](https://docs.kore.ai/xo/getting-started/accessing-the-platform/?h=supported#give-access-to-the-platform).
3. Set up your workspace to centralize users, apps, and permissions, such as: 
    * **Organize: **Collaboration of users, apps, and permissions assigned automatically via email domain or created manually.
    * **Types**: Standard (basic, small teams) and Enterprise (scalable, advanced, custom roles).
    * **Roles**: Master Admin (full access), Admin (manage users/apps), Builder (build only), Viewer (read-only); custom roles in Enterprise.
    * **Access**: Join via domain match or create or invite; only authorized Admins can send invites.
    * **Navigation & Sharing**: Switch workspaces via the workspace switcher; share apps using the plus icon with role-based invites. [Learn more](https://docs.kore.ai/xo/getting-started/accessing-the-platform/?h=supported#using-workspace). 
    * **Upgrade**: Upgrade to Enterprise workspace to access licensed products, convert trial prompts into **Create New** actions, and eliminate the need for reactivation. [Learn more](https://docs.kore.ai/xo/manage-assistant/plan-and-usage/accounts-or-workspace-overview/#upgrade-flow-for-enterprise-workspace).
    * **Ownership & Management**: Grants workspace owners centralized control over multiple bot accounts, plans, usage, billing, credits, analytics, and support. [Learn more](https://docs.kore.ai/xo/manage-assistant/plan-and-usage/accounts-or-workspace-overview/#workspace-linked-to-multiple-apps).

    **Note**: Users only have access to the account where permissions are granted.
