# Accessing Prompt Studio 

Steps to access Prompts:



1. [Sign in](https://galeadmin-kore.github.io/docs/gale/getting-started/sign-up-sign-in/#sign-in-to-gale) to your GALE account.
2. On the top navigation bar, click **Prompts.**
3. On the **Prompts** page, click **New prompt**.
4. On the **Prompts** dashboard, you can see the following tabs:
    * All prompts
    * My prompts
    * Shared prompts

    The tabs display the following information:  

    **Name**: The title or name of each prompt.  
    **Prompt**: The description of the prompt.  
    **Created by**: The name of the individual who created the prompt.
   

5. To create a new prompt, click **New prompt.
**
6. On the **New prompt** dialog, enter a name for your prompt, and click **Proceed**.
The Prompt landing page is displayed.

7. On the Prompt landing page, choose one of the three options to start your prompt creation journey:

    * **Generate a prompt**
    * **Start from scratch**
    * **Prompt library**


### Generate a Prompt

The Generate a prompt option uses AI suggestions to help you create effective prompts, simplifying the prompting process and reducing the learning curve. It provides tailored recommendations, making it easier for users to formulate prompts that meet their needs. 

Steps to create prompts from Prompt library:

1. On the Prompts landing page, click **Generate a prompt.
2. In the Prompt generator dialog, select a model and enter your instruction.

3. Review the AI-suggested prompts.

You can also get assistance in generating a prompt in the prompt canvas by clicking the **Generate Prompt** icon in the Prompt field. This feature provides users with helpful suggestions and options to enhance their prompt creation process.

### Start From Scratch

The Start from Scratch option lets you create prompts right from scratch. When you select this option, you will be directed to a blank prompt canvas, where you can add your prompts, add variables manually or by importing data, add models, and generate your output.

Additionally, you can generate AI responses and incorporate templates from the Prompt Library to enhance your prompt creation process. This flexibility ensures you can tailor prompts to meet your specific needs effectively.

### Prompt Library

The Prompt Library includes a collection of 65+ built-in templates, each comprising a set of system prompts and human prompts. Within the library, you can start crafting your own prompts by selecting from a range of carefully designed templates tailored for various use cases. The Prompt library simplifies the prompt creation process and enhances your productivity by enabling you to access high-quality prompts without the need for manual editing.

The Prompt library contains a variety of optimized prompts for different applications (e.g., code generation, summarization, content creation, Q&A), significantly speeding up experimentation and reducing prompt development time. 

The Prompt library includes a search functionality, where users can easily find prompts by keywords in their names. It also includes a filtering functionality where users can dynamically filter the prompt list by predefined use case categories, enhancing usability and relevance.

Steps to create prompts from Prompt library:

1. On the Prompts landing page, click **Prompt library**.
2. On the Prompt library dialog, select any of the available options. 
**My templates**:  View and manage your saved templates. If you have not saved any templates, this section will be empty. 
**All templates**:  Browse a list of available templates. 

3. Click your desired template. A dialog box with the system prompt and prompt is displayed. To use the template, click **Use template**.  

4. Once you click **Use template**, the prompts will be copied to the prompt canvas. You can then customize the prompts as needed.

**Note**: All the prompt templates are read-only, preventing direct editing of predefined prompts. You can edit the content only when you use the template in the prompt canvas.

For more information on how to create prompts on the prompts canvas, see &lt;*Using Prompt Studio*>.
